## 兼容性发现与处理

首次真实安装成功，但旧健康检查在启动 404 时提前失败。独立观测确认新版先返回 404，随后进入 401。上游 `dsh-host-webserver` 在页面 fallback 注册前已监听端口，`dsh-client-connection` 要求启动 URL 的进程令牌交换为 Cookie 后才能访问 HTML。

先新增五个 404/401 重试及取消用例，旧实现五项均失败；适配后全部通过。新增内存会话从当前 Owned 进程标准输出捕获严格认证公告，认证 URL 不进入配置、状态快照或日志。HTTP 探测与 Code WebView2 使用各自 Cookie 会话；认证后仍要求原有 HTML 双身份标记。外部未认证服务继续拒绝加载。

安全回归覆盖编码参数、重复参数、片段、用户信息、非根路径、相邻恶意域名、错误端口、认证前后跨源重定向零请求、输出脱敏和退出清理。localhost / IPv6 配置可采用同 scheme/端口的官方 IPv4 公告源，令牌不会发送到别名地址。详细评审见详细设计第 37.1 节。
