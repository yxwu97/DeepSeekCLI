原型设计规格

产品边界

桌面端只负责 DSH 进程生命周期和 WebView2 宿主能力。模型、会话、审批和工具操作继续由官方 Web UI 提供。

界面结构

窗口标题栏应用身份与系统窗口操作
桌面控制栏工作目录、运行状态、刷新、重启和停止
内容区域WebView2 或原生启动状态页
状态栏进程所有权、渲染引擎和当前地址

关键交互

  • 刷新只重新加载页面，不重启 DSH。
  • 重启严格执行停止完成后再启动。
  • 停止只结束当前应用创建的进程树。
  • 外部实例可连接，但停止与重启不可用。
  • 切换工作目录时，运行中的实例需要重启。

状态覆盖

控制栏中的“原型场景”可切换运行中、启动中、已停止、启动失败和外部实例五种界面状态。
